## Заметки по источникам (заполнять по ходу)
- Travelpayouts (проверено 2026-10-03, `market=sk`, `currency=eur`, v3 `prices_for_dates`, `one_way=true`):
  - Кэш даёт данные по всем 18 проверенным аэропортам, но в ноябре у LTN/STN, в декабре у FCO/MLA ответ пустой: покрытие неравномерное, чем дальше дата, тем меньше предложений.
  - Больше половины ответов — рейсы с пересадками (535 всего, 318 прямых). По ATH, BER, BRU (город) прямых нет вообще. Поэтому в `routes.yaml` стоит `max_stops: 0`; сырой ответ в `raw.fetch_log` хранится целиком.
  - Запрос по коду города возвращает другие аэропорты: BRU → CRL, OSL → TRF, LON, STO, MIL, ROM → LTN/STN, ARN, BGY, FCO. Берём `origin_airport` из ответа.
  - Один `offer_id` могут дать несколько вариантов (23 из 535): оставляем самый дешёвый.
  - `flight_number` у API — только номер без кода авиакомпании; мы сохраняем `airline + number` (напр. `FR3035`).
  - Реальный полный запуск: 56 запросов, 0 ошибок, 307 прямых предложений из 15 аэропортов, около 40 с на запуск. Лимитов не встретили.
  - Вывод для оценки объёма: один сбор даёт ~300 прямых предложений (горизонт 90 дней), поэтому 10 000 «билетов» набирается в основном проданными местами генератора, а не предложениями.
- Wizz Air: **отклонён** (2026-10-03). Сайт отвечает 405 и интерактивной проверкой «Human Verification»; обход = обход защиты, не делаем. См. `docs/zdroje/wizzair.md`.
- Ryanair (проверено 2026-10-03, реальный запуск: 24 запроса, 0 ошибок, 20 предложений из 6 аэропортов):
  - Fare Finder API открыт, токен не нужен. На окно дат возвращает одну самую дешёвую поездку, поэтому делаем запрос на каждый день (≈13 аэропортов × 90 дней ≈ 1170 запросов, ≈ 30 мин при паузе 1,5 с).
  - Эндпоинт `availability` (расписание дня, места) закрыт защитой (409), не используем. Числа мест у Ryanair в доступных данных нет, места симулирует генератор.
  - Доступные аэропорты: ARN BCN BGY CPH CRL DUB EIN LTN MAD MLA STN TRF VIE (13). FCO, OSL, BRU у Ryanair не маршруты в KRK.
  - Пересечение с Travelpayouts: оба показывают рейсы FR. Разные источники дают разные `offer_id`, так что дубли по содержанию допустимы.
  - Оценка объёма: до ~1000 предложений Ryanair за 90 дней плюс ~300 Travelpayouts.
