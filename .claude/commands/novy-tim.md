Добавь в data lake адаптер для команды: $ARGUMENTS

1. Я дам (или уже дал) описание их интерфейса: протокол, адрес, формат. Если чего-то не хватает — спроси.
2. Опиши их интерфейс в docs/timy/<команда>.md (как они отдают данные, своими словами, без нормализации).
3. Напиши lake/adapters/<команда>.py по общему интерфейсу адаптера, учётные данные — только через .env.
4. Добавь источник в config/lake_sources.yaml.
5. Сохраняй сообщения как есть (сырые байты + jsonb, если это JSON). Никакой нормализации — это работа warehouse.
6. Тест адаптера на записанных примерах их сообщений.
